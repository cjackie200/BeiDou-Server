# 服务端 v2.7.4 更新说明

- 一至四转技能点重置卷改为重置对应转职阶段全部技能，并一次性返还全部技能点。
- 帮助菜单新增批量洗点，可依次选择来源属性、洗点数量和目标属性。
- 批量洗点在执行前校验能力点与洗点能力卷数量，并按实际完成数量扣除卷轴。
- 批量洗点支持力量、敏捷、智力、运气、HP和MP；HP/MP可互相转换到职业系统最低线，不受手动投入HP/MP的AP次数限制。每次转换沿用原版职业固定扣除和成长公式，不按数值1:1转换，并保留生命之证限制。
- 黑悟空任务接取后灯泡会消失，完成击杀条件后重新出现用于交付任务。
- 生命之证与帮助洗血路线严格二选一：已接生命之证只显示四维，帮助洗过HP/MP后不能再接生命之证。
- 龙神等特殊技能重置卷继续保留原版处理方式。
