# 服务端 v2.7.7 更新说明

## 全服仓库优化

- 普通物品不再按存入玩家分组，相同物品自动合并数量。
- 仓库列表不再显示存入角色和存入时间。
- 查看装备时新增通用、战士、魔法师、弓箭手、飞侠、海盗分类。
- 取出堆叠物品时可以选择本次取出数量。
- 存入单个物品时先选择装备、消耗、设置或其他背包页签。
- 服务启动后自动合并全服仓库中已有的同类普通物品。

## 部署说明

- 停止服务端后运行 `BeiDou-Server-v2.7.7-global-storage-patch.exe`。
- 选择包含 `BeiDou.jar` 的服务端工作目录。
- 更新完成后重新启动服务端，Flyway 会自动执行 `V1.11.49` 数据迁移。
- 本次不需要更新客户端。
