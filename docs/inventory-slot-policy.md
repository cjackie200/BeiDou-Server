# 背包栏位策略

当前普通背包栏位策略是不突破客户端稳定上限，只把默认值补到最大值。

- 新建角色的 `EQUIP`、`USE`、`SETUP`、`ETC` 初始栏位为 96。
- `CASH` 背包固定按 96 返回。
- 商城扩展券、GM 调整或其他扩展入口仍不能把普通背包扩到 96 以上。
- Flyway `V1.11.12__set_default_inventory_slots_96.sql` 会把旧角色普通背包栏位统一校正为 96，并把 `characters` 表对应字段默认值改为 96。
- 执行该迁移时应停服，避免在线角色在迁移后又保存旧栏位值。

本策略不包含突破 96。若后续需要超过 96，必须先验证客户端背包 UI、物品栏协议、槽位序列化和所有扩展入口是否支持更大值。
