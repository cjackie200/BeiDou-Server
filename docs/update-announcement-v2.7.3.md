# v2.7.3 分阶段突破任务更新说明

## 技能突破

- 突破任务改为按一转、二转、三转、四转分阶段开放，每阶段只解锁本转技能并赠送对应 SP。
- 一转挑战木妖王 3 只，二转挑战树妖王 3 只，三转挑战肯德熊 3 只，四转挑战扎昆 1 只。
- 某职业在对应转职没有突破技能时自动跳过该阶段；遗漏任务可在高转后按顺序补做。
- 旧版突破任务已完成角色保留全部解锁；旧任务进行中角色保留扎昆进度，并按旧待遇结算。
- 技能详情中的突破等级说明改为完成对应转职突破任务后可学习。
