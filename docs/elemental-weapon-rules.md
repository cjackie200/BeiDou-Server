# 元素武器规则

本文记录中文服元素杖当前规则，避免服务端 WZ、客户端 Data、装备实例持久化和 `ijl15` DLL 之间出现双算或口径不一致。

## 当前倍率

- 元素杖只保留一个主属性加成，主属性 `incRMA*` 按等级档位递增：
  70/103/133/163/193 档分别为 `140/155/170/185/200`。
- 副属性加成已取消，不再保留 `110%` 副属性。
- `elemDefault` 也按等级档位递减，表示元素杖遇到非主属性元素技能时的保留倍率：
  70/103/133/163/193 档分别为 `90/80/70/60/50`。
- 中立或无属性技能不应因为元素杖受到惩罚，保持原始 `100%`。
- 全部元素短杖 / 长杖取消运气需求，`reqLUK = 0`。
- 基础魔法力直接按 `20 + reqLevel` 配置；70/103/133/163/193 档分别为
  `90/123/153/183/213`。
- 附加 INT 按等级档位序号 `* 2` 配置；70/103/133/163/193 档分别为
  `2/4/6/8/10`。
- 附加 LUK 与附加 INT 保持一致；70/103/133/163/193 档分别为
  `2/4/6/8/10`。
- 元素杖定位为专属任务投放装备，装备限制字段统一为 `tradeBlock = 1`、
  `only = 1`、`notSale = 1`、`storageBlock = 1`，对应不可交易、唯一持有、
  不可售卖、不可存仓库。
- 装备描述只保留一行法师风格文案，例如 `星焰在赤曜杖心永恒燃烧。`；元素倍率由
  `ijl15` 在装备属性区按属性条目显示，不再写入描述正文。不可交易、不可存仓、
  唯一持有等限制交给装备限制标签体现。

## 字段对应

- 火属性：`incRMAF`
- 毒属性：`incRMAS`
- 冰属性：`incRMAI`
- 雷属性：`incRMAL`
- 圣属性：`incRMAH`
- 未匹配元素倍率：`elemDefault`

当前客户端 Data 和服务端中文 WZ 的元素杖节点必须同向维护：

- 服务端属性资源：`gms-server/wz-zh-CN/Character.wz/Weapon`。
- 服务端中文名称与描述：`gms-server/wz-zh-CN/String.wz/Eqp.img.xml`。
- 客户端中文资源：`BeiDou-Client/Data/Character/Weapon` 和
  `BeiDou-Client/Data/String/Eqp.img`。
- 不维护 `gms-server/wz/String.wz/Eqp.img.xml` 或 `BeiDou-Client/EN` 的英文回退名称。

每个元素杖节点只应存在一个主属性 `incRMA*` 和一个 `elemDefault`，且 `incLUK`
必须与 `incINT` 相同。
服务端 `Equip` 和 `inventoryequipment` 需要完整保存 `incRMAF/incRMAS/incRMAI/incRMAL/incRMAH/elemDefault`。
任务链正式发布时，`V1.11.30__cleanup_premature_elemental_weapons.sql` 会一次性清理全服提前获得的
70-193 档元素杖，覆盖角色背包/身上、仓库、现金仓、雇佣商店、MTS 和全服仓库等持久化位置。
发布后的正常任务产出不应通过启动代码反复清理。

## 客户端与 DLL

客户端原始 WZ/Data 负责最终元素倍率计算。`ijl15` 接收服务端下发的元素配置并记录诊断日志，不再额外改写 `MAGIC_ATTACK` 发包伤害，也不在 `CalcDamage::MDamage` 中叠加倍率。

服务端元素配置包 `0x1006` 的当前布局为 6 个 `short`：

```text
FIRE, POISON, ICE, LIGHTNING, HOLY, elemDefault
```

`ijl15` 仍兼容旧的 5 个 `short` 布局；旧布局按 `FIRE, POISON, ICE, LIGHTNING, elemDefault` 解析，圣属性视为 0。

这样可以避免匹配属性被原始客户端和 DLL 双重放大，同时保留原始客户端对 `elemDefault` 的分档惩罚行为。

## 服务端校验

服务端伤害校验从装备 WZ 读取当前 `incRMA*` 主属性倍率，用于放宽对应元素技能的最大伤害校验。非主属性技能不额外放宽；客户端如果因 `elemDefault` 发出较低伤害，仍低于服务端上限，不需要服务端单独乘惩罚倍率。

## GM 验收指令

- `!elementweapons`：GM2 及以上可用，一次性向当前角色发放全部 25 把元素短杖 / 长杖。
- 使用前装备栏至少需要 25 个空位；低于 GM3 的账号会沿用 `!item` 的试用限制标记。
- `!elementready`：GM2 及以上可用，补齐当前进行中的元素共鸣步骤测试条件。Boss 步骤补当前
  Boss 凭证，普通材料步骤补缺失材料和金币，奖励选择步骤补跨属性备用材料和金币；该指令不强制
  接任务、不跳隐藏桥、不直接完成奖励。

## 投放任务链

元素杖通过汉斯 `1032001` 发布的 `元素共鸣` 任务链投放，归类到任务区域
`传奇之路`。任务 ID 为 `29991..29995`，开启等级分别为
`70/100/130/160/190`。任务脚本位于
`gms-server/scripts-zh-CN/quest/elementalResonance.js`，服务端状态和兑换规则由
`ElementalResonanceQuest` 控制。
客户端 `Q` 列表使用每个阶段完整标题作为 `parent`，显示为 `元素共鸣:初声`、
`元素共鸣:回响`、`元素共鸣:裂隙`、`元素共鸣:风暴`、`元素共鸣:终章`，避免只显示统一系列名。
进行中的 `QuestInfo.1` 只保留 `@@BD_IH_PROGRESS:{questId}@@` 动态进度占位符，由
`ElementalResonanceQuest.progressEntries` 下发当前 Boss、材料或奖励选择步骤；不要把多步骤目标写成
静态概述。

任务阶段：

- `29991` 元素共鸣:初声：奖励 70 级元素短杖。
- `29992` 元素共鸣:回响：消耗上一阶段任意元素杖，奖励 103 级元素长杖。
- `29993` 元素共鸣:裂隙：消耗上一阶段任意元素杖，奖励 133 级元素短杖。
- `29994` 元素共鸣:风暴：消耗上一阶段任意元素杖，奖励 163 级元素长杖。
- `29995` 元素共鸣:终章：消耗上一阶段任意元素杖，奖励 193 级终阶元素短杖。

每个阶段不是一次性交齐全部条件，而是按服务端状态机多步骤推进：

1. 按顺序击败当前阶段的每个 Boss。每次只需要当前 Boss 的 1 枚共鸣凭证，回到汉斯处报告后
   消耗该凭证，并写入对应 Boss 隐藏桥，然后开放下一个 Boss 步骤。
2. 交付当前阶段普通材料和基础金币。交付后消耗普通材料、基础金币，并写入本阶段材料隐藏桥。
3. 选择 5 选 1 元素杖并完成重铸。`29992..29995` 在这一步消耗上一阶段元素杖；如果跨属性
   重铸，只在这一步额外消耗星石、黑水晶和金币。

隐藏桥任务 ID 为 `29950..29970`，每个 Boss 一个桥，再加每阶段一个材料桥。隐藏桥不写玩家可见
`parent/order/area`，不出现在任务分类中，只用于持久化阶段内步骤。
可见任务的 WZ 完成条件只使用 `infoex=001`；真实步骤条件和材料扣除由
`ElementalResonanceQuest` 控制。
任务状态入口和汉斯 NPC 点击由 `InteractionHook` 接管，不在 `1032001.js` 中手写
`元素共鸣/其他事务` 菜单，避免 NPC 原生对话和任务脚本状态串台。

Boss 共鸣凭证为 `4033012..4033027`，均为任务道具，配置
`tradeBlock=1`、`storageBlock=1`、`notSale=1`、`quest=1`、`slotMax=1`。
掉落由 `drop_data.questid` 绑定对应阶段，服务端再按当前 Boss 步骤过滤 `mobId` 和凭证 ID：
未接任务、当前步骤不匹配、已持有当前凭证或已经报告过该 Boss 时，凭证不会显示为可掉落或可拾取。
组队击杀时，符合当前步骤的同地图队员各自生成一份个人凭证；个人凭证只对本人可见，也只能由本人
或本人的宠物拾取，不会因组队共享或所有权过期被队友拾取。

Boss 凭证来源：

- `29991`：红蜗牛王 `2220000`、树妖王 `3220000`、蘑菇王 `6130101`。
- `29992`：巨居蟹 `5220000`、浮士德 `5220002`、提莫 `5220003`。
- `29993`：多尔 `6220000`、僵尸蘑菇王 `6300005`、蝙蝠怪 `8130100`。
- `29994`：蝙蝠魔 `8150000`、喷火龙 `8180000`、格瑞芬多 `8180001`。
- `29995`：帕普拉图斯 `8500002`、扎昆 `8800002`、暗黑龙王 `8810018`、
  品克缤 `8820001`。

普通材料全部使用当前版本已有可触达材料，不使用 `4001108 冰核`。`29993` 和
`29995` 需要黑水晶与星石替代冰核路线。玩家可以跨属性重铸，但从 `29992` 开始，
如果选择的奖励属性与上一阶段元素杖不同，需要额外消耗星石、黑水晶和金币。

职业与限制规则：

- `29991..29995` 开放给 `200..299` 法师职业段；初声在 70 级开启，不要求已经二转。
- `29991` 不需要上一阶段元素杖；玩家没有任何元素杖时可以重新从 `29991` 开始。
- `29992..29995` 必须提交上一阶段任意元素杖，元素杖必须在装备栏背包内。
- 装备中的元素杖不能直接升级，必须先卸下。
- 如果玩家同时持有多把元素杖，拒绝继续，避免唯一持有状态异常。
- 奖励装备继续保持不可交易、不可存仓、不可出售、唯一持有。
