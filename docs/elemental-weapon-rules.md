# 元素武器规则

本文记录中文服元素杖当前规则，避免服务端 WZ、客户端 Data 和 `ijl15` DLL 之间出现双算或口径不一致。

## 当前倍率

- 元素杖只保留一个主属性加成，主属性 `incRMA*` 按等级档位递增：
  70/103/130/163/193 档分别为 `140/155/170/185/200`。
- 副属性加成已取消，不再保留 `110%` 副属性。
- `elemDefault` 也按等级档位递减，表示元素杖遇到非主属性元素技能时的保留倍率：
  70/103/130/163/193 档分别为 `90/80/70/60/50`。
- 中立或无属性技能不应因为元素杖受到惩罚，保持原始 `100%`。
- 全部元素短杖 / 长杖取消运气需求，`reqLUK = 0`。
- 基础魔法力直接按 `20 + reqLevel` 配置；70/103/130/163/193 档分别为
  `90/123/150/183/213`。
- 附加 INT 按等级档位序号 `* 2` 配置；70/103/130/163/193 档分别为
  `2/4/6/8/10`。

## 字段对应

- 火属性：`incRMAF`
- 毒属性：`incRMAS`
- 冰属性：`incRMAI`
- 雷属性：`incRMAL`
- 圣属性：`incRMAH`
- 未匹配元素倍率：`elemDefault`

当前客户端原始 Data 和服务端 WZ 的元素杖节点必须同向维护：

- 服务端属性资源：`gms-server/wz/Character.wz/Weapon`。当前仓库没有
  `wz-zh-CN/Character.wz` 覆盖树，装备属性仍由 base Character WZ 承载。
- 服务端中文名称：`gms-server/wz-zh-CN/String.wz/Eqp.img.xml`。
- 客户端中文资源：`BeiDou-Client/Data/Character/Weapon` 和
  `BeiDou-Client/Data/String/Eqp.img`。
- 不维护 `gms-server/wz/String.wz/Eqp.img.xml` 或 `BeiDou-Client/EN` 的英文回退名称。

每个元素杖节点只应存在一个主属性 `incRMA*` 和一个 `elemDefault`。

## 客户端与 DLL

客户端原始 WZ/Data 负责最终元素倍率计算。`ijl15` 接收服务端下发的元素配置并记录诊断日志，不再额外改写 `MAGIC_ATTACK` 发包伤害，也不在 `CalcDamage::MDamage` 中叠加倍率。

服务端元素配置包 `0x1006` 的当前布局为 6 个 `short`：

```text
FIRE, POISON, ICE, LIGHTNING, HOLY, elemDefault
```

`ijl15` 仍兼容旧的 5 个 `short` 布局；旧布局按 `FIRE, POISON, ICE, LIGHTNING, elemDefault` 解析，圣属性视为 0。

这样可以避免匹配属性被原始客户端和 DLL 双重放大，同时保留原始客户端对 `elemDefault` 的分档惩罚行为。

## 服务端校验

服务端伤害校验从装备 WZ 读取当前 `incRMA*` 主属性倍率，用于放宽对应元素技能的最大伤害校验。非主属性技能不额外放宽；客户端如果因 `elemDefault` 发出较低伤害，仍低于服务端上限，不需要服务端单独乘惩罚倍率。

## GM 验收指令

- `!elementweapons`：GM2 及以上可用，一次性向当前角色发放全部 25 把元素短杖 / 长杖。
- 使用前装备栏至少需要 25 个空位；低于 GM3 的账号会沿用 `!item` 的试用限制标记。

## 投放规划

以下为计划口径，尚未落地为任务脚本、任务 WZ 或掉落配置。

70 级元素短杖建议放到魔法师一转教官汉斯 `1032001`：

- 入口条件：法师职业线、等级不低于 70、完成二转。
- 任务形式：汉斯开启高难度“元素共鸣试炼”系列任务。
- 过程建议：先完成基础魔法理论考核，再分别收集火、毒、冰、雷、圣五类试炼材料，最后挑战一个限时战斗或精英怪试炼。
- 奖励建议：完成后从 5 把 70 级元素短杖中选择 1 把；重复获取需要额外材料和冷却，避免初期直接刷满五属性。

后续阶段建议：

- 103 级元素长杖：作为中期副本 / 组队任务代币兑换，要求玩家已经完成 70 级试炼链。
- 130 级元素短杖：采用升级制作路线，用对应 70 级短杖、稀有矿石和中高阶 boss 代币合成。
- 163 级元素长杖：放入高阶 boss 掉落或高阶远征队代币兑换，控制产出速度。
- 193 级终阶元素短杖：走终阶升级链，不建议直接掉落；用 130 / 163 对应属性武器、终阶 boss 材料和大量金币合成，作为长期追求目标。
